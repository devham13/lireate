# TOO_MANY_DOMAINS_ON_SEARCH (Яндекс Webmaster, 2026-11-27)

**Действие:** только анализ. Другие домены **не менять** без владельца.

## Что видит Яндекс

В выдаче/привязках фигурируют:

- `lireate.online` и субдомены
- `sam.lireate.*` (зеркала/legacy DNS)

Канон хоста в SEO-слое: **`https://lireate.ru`**.

## Гипотезы

1. Старые DNS A/CNAME на тот же `public_html` без 301 на `lireate.ru`.
2. Зеркала с тем же контентом (SQI на основном — 50).
3. Ссылки в старых материалах на альтернативные хосты.

## Рекомендации (для решения владельца)

| Шаг | Риск |
|-----|------|
| В Вебмастере: указать предпочтительное зеркало `https://lireate.ru` | низкий |
| На зеркалах: 301 на канон **или** `noindex` + канон link | средний (нужен доступ к каждому vhost) |
| Аудит внутренних ссылок и sitemap — только `lireate.ru` | низкий (репо/cron) |

**Не делать:** массовый 301 без карты хостов; не трогать `lireate.online`/subdomains из Cloud без explicit approve.
