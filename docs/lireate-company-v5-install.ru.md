# LIREATE — единый Light V5 для пяти информационных страниц + исправление логотипа

Дата подготовки: 26.11.2026. **Это исходники и PR, не публикация на REG.RU.**

## Что охвачено

- /o_kompanii — история компании и управляющие партнёры. Hero с **реальной** фотографией Эльвиры Габдрахмановой (файл уже использован на главной), подпись должности. История и данные партнёров не меняются.
- /team — карточка сотрудника в hero, существующий список сотрудников, должности и модальные окна сохранены.
- /partners — блок «Партнёрство, которое работает», современная сетка партнёров; имена, контакты, адреса и услуги выводятся из исходных данных.
- /docs — первый экран с векторной иллюстрацией документа, светлые карточки файлов и реквизитов. Ссылки, реквизиты, открытия и скачивания сохраняются.
- /contacts/ — первый экран с иллюстрацией офиса, форма заявки, адрес, карта, телефоны и соцсети сохраняются.

Единые цвета: белый фон, тёмный #1F212C, красный #E32020, синий #195ACB / #3A86FF,
голубой #F3F8FF. 3D, градиентные кислотные темы и тёмные блоки не добавляем.

## Исправление логотипа левого меню

Выяснено по исходникам: `template/images/logo/logo.svg` имеет viewBox 759.7 × 136.1;
буквы белые (#FFFFFF) на исходном тёмном фоне. На светлых страницах использовался
CSS mask/background и неполный или одноцветный логотип.

Создан **векторный** `template/images/logo/logo-light-v5.svg` из исходного
SVG — красные графические формы не изменены, белые формы перекрашены в тёмный.
В новых стилях `.leftSideLogo` рисуется целиком через `background-size:contain`
без mask, с предсказуемой шириной и центрированием. **Не использовать
обрезанный скриншот или другой логотип.**

## Подход к PHP-CMS

Пять исходных страниц находятся в `pages/<раздел>/_shared/*-page.inc.php`,
а реальные развернутые PHP-templates — в `template/page/<раздел>/*-page.inc.php`.
В PR обновлены обе группы (10 шаблонов): подключён общий CSS, body-класс и
семантическая карточка справа в первом экране. **Не создаётся второй H1**.
Оригинальное содержимое, формы, action-URL, Метричные data-lx-ym-goal,
информация о сотрудниках, партнёрах, документальных материалах,
пункты меню и футер не переписаны.

Добавлено:
- `template/css/lireate-company-pages-v5.css` — общие стили для 5 страниц;
- `template/images/logo/logo-light-v5.svg` — исходный логотип для белого фона;
- `scripts/lireate_company_v5_install.py` — host installer, dry-run по умолчанию,
  бэкап и откат, PHP lint, защита от перезаписи более свежих live-файлов;
- `scripts/test_lireate_company_v5_install.py` — офлайн регрессионные тесты.

## Cursor/Grok: перед установкой

1. Прочитать `AGENTS.md`, `docs/lireate-design-system-v4.ru.md` и данный файл.
2. Скачать PR-ветку отдельно от рабочего checkout, которым пользуется CRON.
3. По SSH прочитать текущие реальные PHP-файлы на REG.RU. Определить
   `LIREATE_DOCROOT` по фактическому месту сайта, не угадывать.
4. Проверить, что эти 5 URL использует ровно те `template/page/*` файлы.
5. Запустить `python3 scripts/test_lireate_company_v5_install.py`.
6. Запустить dry-run:
   `python3 scripts/lireate_company_v5_install.py --docroot "$LIREATE_DOCROOT" --backup-root "$HOME/lireate-autopub/backups/company-v5"`
7. Если сообщение **BLOCKER: live PHP differs** — остановиться. Это означает,
   что Cursor/Grok или хостинг уже изменили live PHP поверх старой версии
   main. **Не перезаписывать** такие файлы. Перенести только новую разметку
   hero, CSS и проверенный SVG на текущую версию, обновить PR и проверить снова.
8. Перед применением проверить наличие PHP CLI и css/svg на сервере; если CSP
   запрещает ресурсы, устранить это безопасно, без ослабления политики целиком.

## Установка после успешного QA

`python3 scripts/lireate_company_v5_install.py --docroot "$LIREATE_DOCROOT" --backup-root "$HOME/lireate-autopub/backups/company-v5" --apply --php-bin php`

Установщик создаёт резервную копию только затрагиваемых файлов **вне DOCROOT**,
выполняет атомарные замены и PHP syntax check. При ошибке автоматически откатывает.

После применения проверить:
- /o_kompanii, /team, /partners, /docs, /contacts/ на desktop (1440px, 1920px),
  tablet (768px) и mobile (320px, 375px, 390px);
- логотип слева полностью виден в обычном и свёрнутом меню, не белый на белом,
  не обрезан, кликабелен, без 404 по новому SVG;
- настоящие данные команды/партнёров, PDF и реквизиты, карта, форма и чекбокс
  согласия, телефоны, MAX/Telegram/WhatsApp, старые цели Метрики;
- все ссылки, собственно левое и верхнее меню, отсутствие дублирования,
  1 H1, title, description, canonical, CSS/JS ошибки и горизонтальный overflow;
- CRON не перезаписывает эти шаблоны после очередной синхронизации.

Отчёт: скриншоты 5 страниц desktop/mobile + отдельный скриншот логотипа в
левом меню, список изменённых файлов, исходный путь backup, результаты smoke
tests. В случае ошибки сделать `--rollback /путь/к/backups/<timestamp>` с
прежним `--docroot`.

**Без подтверждения не выполнять автоматический merge PR в main.**
Нельзя утверждать, что сайт опубликован, пока реальные 5 страниц не проверены.
