Верхнее меню: Услуги, Команда, Кейсы, Стоимость, Этапы, FAQ, Блог. Нумерацию убрать; увеличить шрифт и равномерно распределить пункты. Сохраняются телефон +7 (960) 048-49-57, кнопка «Оставить заявку», активное красное подчёркивание.

Левое меню: все существующие категории и вложенные услуги CMS, без поиска «Найти услугу или раздел». Сохраняются текущие SVG Telegram, WhatsApp, MAX, VK, YouTube, ссылки и обе телефонные кнопки +7 (499) 938-45-95, +7 (960) 048-49-57. Все иконки синего цвета с красным hover. На мобильном используется исходный CMS burger; не создавать вторую шапку.

## Что сделано в репозитории

- template/css/lireate-navigation-dual-v3.css — применяет стиль к фактической разметке #leftSideBar, .leftSideSoc, .leftSideTel и .lh4-subnav.
- template/js/lireate-navigation-dual-v3.js — помечает активный раздел в верхней строке; не меняет CMS-меню, формы, адреса.
- scripts/lireate_hosting_navigation_v3.py — безопасно копирует эти два ассета в DOCROOT и идемпотентно вставляет подключения в общий template/main.php.

В repo нет live template/main.php и leftSideNav*.php — они живут на хостинге REG.RU. Поэтому PR только готовит внедрение, не считается публикацией.

## Применение через Grok/Cursor после одобрения

1. Изучить AGENTS.md, текущий хостинговый main.php, проверить действующие меню и контакты.
2. Сделать git fetch / checkout утверждённого main на хостинге; не менять news-репозиторий или базу.
3. Назначить LIREATE_DOCROOT, соответствующий реальному DOCROOT (из документации: $HOME/www/public_html).
4. Запустить dry-run без записи:

    python3 scripts/lireate_hosting_navigation_v3.py --docroot "$LIREATE_DOCROOT" --backup-root "$HOME/lireate-autopub/backups/navigation"

5. Проверить, что меняются только template/main.php и два ассета меню. При явном согласовании выполнить:

    python3 scripts/lireate_hosting_navigation_v3.py --docroot "$LIREATE_DOCROOT" --backup-root "$HOME/lireate-autopub/backups/navigation" --apply --php-bin php

6. Проверить live главную, /registraciya_tovarnogo_znaka/, /news/, /team; переходы, CTA, телефоны, соцсети, формы, Метрику, мобильный burger, отсутствие горизонтальной прокрутки, клавиатуру и reduced motion. Не допускать потери SEO.
7. Если проблема — запустить --rollback с путём к каталогу резервной копии, который выдал установщик. Резервные копии находятся вне DOCROOT.

## Проверка

Установщик проверен на локальном аналоге PHP-CMS: dry run, apply, повторный NO_CHANGES, rollback. CSS прошёл синтаксический парсер, JS проверен на синтаксис. На реальном REG.RU не запускалось.

Важно: без согласования не сливать PR в main и не выполнять --apply. Скрипт не правит data/db.php, CMS меню и контакты, контент страниц, SEO, аналитику, consent и реальные формы.
