# Unslop для LIREATE

Unslop помогает дорабатывать интерфейсы: отступы, типографику, цвета, композицию,
детали и тексты. Автор — **Damir Sokolovsky (heydamir)**.
Исходник: https://github.com/heydamir/unslop.

## Использование

Навык находится в `.agents/skills/unslop/`, общем каталоге навыков Cursor и Codex.
В Cursor выбрать `/unslop` в чате агента; в Codex указать `$unslop`.
Если автоматическое обнаружение недоступно, попросить агента прочитать
`.agents/skills/unslop/SKILL.md` и применить его к указанной странице.

Пример запроса: «Примени Unslop к странице услуги: сначала проведи аудит дизайна
и предложи изменения с учётом фирменного стиля LIREATE».

При работе с LIREATE сохранять требования `AGENTS.md`,
`docs/lireate-service-design.ru.md`, общие ассеты страниц услуг, SEO-метаданные,
адреса страниц и работающие формы. Установка навыка сама по себе не меняет сайт.

репозитория `heydamir/unslop`. Файлы навыка скопированы без изменений; добавлена

`.agents/skills/unslop/LICENSE`. Авторство сохранено в `SKILL.md`.
Источник и контрольные суммы указаны в `tools/design/unslop.lock.json`.

запуска нужны зависимости из инструкций автора (Playwright/Chromium, для видео —
ffmpeg); сама установка навыка их не запускает и не устанавливает.
